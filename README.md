# React Admin Dashboard

Dashboard administrativo interactivo desarrollado con React, Tailwind CSS y Syncfusion.

El proyecto reúne diferentes componentes de interfaz y módulos comunes en aplicaciones empresariales.

## Módulos incluidos

- Panel principal.
- Gráficas.
- Calendario.
- Kanban.
- Gestión de clientes.
- Gestión de empleados.
- Órdenes.
- Carrito de compras.
- Editor de texto enriquecido.
- Selector de colores.
- Configuración de temas.
- Chat.
- Diseño adaptable.

## Tecnologías

- React
- React Router
- Tailwind CSS
- Syncfusion EJ2
- JavaScript
- ESLint
- React Icons

## Instalación

```bash
npm install
npm start
```

Para generar una versión de producción:
```bash
npm run build
```
## Objetivo
Este proyecto demuestra habilidades en desarrollo frontend, diseño de interfaces, reutilización de componentes, navegación entre vistas y creación de dashboards administrativos.
